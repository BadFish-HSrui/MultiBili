# Multi Bili
一个基于[KMP (Kotlin MultiPlatform)](https://kotlinlang.org/multiplatform/)的开源全平台B站客户端实现
> 全平台指 `Android` `iOS` `MacOS` `Linux` `Windows`
>
> 虽然理论上KMP支持`JS`和`WASM`，但因为依赖生态与运行效率问题，本项目短期内不会考虑Web版本(B站网页端还挺好用的)

### 本项目不包含以下特性：
- :thumbsup: 丝滑的使用体验
- :pencil2: 精心设计的UI
- :art: 高水平审美
- :zap: 运行流畅
- :100: 无BUG
